Atelier is a single-file web app for artists, designers and makers. It keeps your references, moodboards, projects, color palettes, fonts, journal and finished work in one place, inside a cozy virtual studio room you can decorate.

There is nothing to install and no account to create. Open Atelier_Creative_Studio.htm in any modern browser and start working. Everything is saved in your browser.

What it does
Section	What you can do
Virtual Studio	A decorated room that acts as the home screen. Click props such as the wall art and the mini moodboard to jump to that section. Customize the room (window frame, wallpaper, plush props) and play built-in lo-fi music.
Moodboard	Pin photos, sticky notes, color swatches and type cards on a draggable canvas. Choose a surface (dot grid, cork, linen, slate), rotate cards, edit text in place, and export the board as a PNG.
Projects	Track creative work through the stages Idea, Sketching, In Progress and Completed. Filter by stage and feature a finished project in your portfolio.
Inspiration	Collect visual references, search them by tag or title, and pin any of them to your moodboard.
Color Palettes	Build 5-color palettes, randomize them, extract colors from an image, and export a palette as PNG or CSS.
Creative Journal	Write studio notes and draw quick sketches on a built-in sketchpad (pen, marker or brush, any color).
Portfolio Corner	Show finished pieces in a gallery with a choice of frame styles.
Font Organizer	Preview your fonts with your own text, upload .ttf, .otf or .woff files, download font kits and specimen posters, and pin fonts to the moodboard.
Image tools: crop, expand and frames

These work in the Portfolio Corner and on Moodboard image cards.

Expand. Click an image to open a full-screen viewer. Use the arrow keys to move between images, switch to actual size, download, and close with Esc.
Crop. The ✂ button opens a crop box that you drag and resize. It has ratio presets (Free, 1:1, 4:5, 3:2, 16:9, Original) and a rotate button. The ↺ button restores the original image.
Resize cards. On the moodboard, drag the round handle at the bottom-right corner of an image card to make it bigger or smaller. The PNG export respects the new size.
Frames. The portfolio has 8 frame styles: Dark gallery, Minimalist, Warm wood mat, Gilded double frame, Polaroid, Film strip, Floating card and Double matte. You can also switch the image fit between filling the frame and showing the whole image.
Moodboard adjustments. The ◐ button adjusts brightness and contrast, zooms and pans, and applies a 2x sharpened upscale.
Font sample downloads

Type any text in the Live Tester box in the Font Organizer. Each font card then has a Sample text row:

PNG is a ready-to-use image of your text in that font.
SVG is a vector version. It links to Google Fonts, so it needs an internet connection to display correctly. Fonts you uploaded are embedded in the file.
TXT is a text file with the font details, your sample text and the CSS to use it.

Use Sample download options to pick the background (font card colors, light, dark or transparent) and the text size. Download all samples (1 PNG) puts every font on a single sheet.

Themes and saving
Themes: Paper (warm), Sage (botanical) and Night (midnight), switched from the sidebar.
Auto-save: your work is stored in your browser's local storage and saved as you go.
Backup JSON: downloads all your data as a file you can keep.
Import: brings files or data into the workspace.
Reset Demo: restores the sample content.
Getting started
Download Atelier_Creative_Studio.htm.
Double-click it to open it in Chrome, Edge, Firefox or Safari.
Pick a section from the sidebar and start adding things.

An internet connection is only needed to load the Google Fonts used by the interface and the built-in fonts. The rest of the app works offline.

Good to know
Your data lives in one browser on one device. Use Backup JSON before clearing your browser data or switching computers.
Browsers limit local storage to a few megabytes. Many large images, and crops (which keep the original too), can fill it. Atelier shows a message when you reach the limit, and removing a few large images frees space.
A moodboard image that comes from another website cannot be cropped, because browsers block editing images from other sites. Upload the file instead.
Built with

Plain HTML, CSS and JavaScript in a single file, with no build step and no libraries. Fonts come from Google Fonts: Plus Jakarta Sans, Playfair Display and Caveat, plus the display fonts in the Font Organizer.
